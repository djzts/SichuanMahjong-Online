# 四川麻将 · 血战到底（在线版）

给熟人朋友玩的四人在线四川麻将网页游戏。纯静态网站，部署在 GitHub Pages 上，不需要服务器，也不需要注册账号。

- 4 人局，以及 5 / 6 / 7 人轮换局（每局 4 人上桌，其余人当临时观察者，按规则轮换）
- 2 个观战位；空位可以加电脑补齐
- 实时积分榜：所有人从 0 分开始，每次杠、胡结算后立即更新
- 单机练习：你对 3 个电脑
- 联机：PeerJS（WebRTC 点对点），房主的浏览器负责洗牌、判定和计分（房主权威）
- 观战者只能看到牌河，收不到任何人的手牌数据
- 断线重连：刷新页面回到原座位；断线期间电脑托管
- 牌面用 SVG 自绘，手机横屏、竖屏都能玩

## 怎么玩

1. 打开网站，输入昵称。
2. **单机练习**：直接开始，你对 3 个电脑。
3. **联机**：一个人点「创建房间」，把 6 位房间号或「邀请链接」发给朋友；朋友输入房间号点「入座」，或者用「观战链接」进来观战。房主在等待室选人数（4/5/6/7 人局），可以把空位设为电脑，号位坐满后点「开始游戏」。单机练习也可以选人数。
4. 出牌：点一下选中、再点一下打出，或者把牌往上滑。能碰、杠、胡时会弹出按钮。

> 房主的浏览器就是这局游戏的“服务器”：房主关掉页面，游戏会暂停。房主刷新后会自动恢复房间（数据存在房主浏览器的 localStorage 里，12 小时内有效），其他人会自动重连。

## 本地运行

需要 Node.js 22（或 20.19 以上）。

```bash
npm install
```

```bash
npm run dev
```

打开终端里显示的地址（例如 `http://localhost:5173/SichuanMahjong-Online/`）。在同一台电脑上多开几个浏览器标签页，就能自己测试联机（每个标签页是一个独立的玩家）。

其他命令：

```bash
npm test        # 规则引擎、对局流程、观战信息隐藏、1000 局 AI 自对局
npm run lint    # ESLint + Prettier
npm run build   # 构建到 dist/
```

调试：打开 `#/solo?debug=1&seed=123`，单机模式下能看到所有人的牌，并固定第一局的随机种子。

## 部署到 GitHub Pages

仓库里已经有 `.github/workflows/deploy.yml`：push 到 `main` 分支会自动跑检查、构建并发布。

第一次需要在 GitHub 上做两件事：

1. 仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。
2. 确保有 `main` 分支，并把它设为默认分支（**Settings → General → Default branch**）。之后每次 push 到 `main` 都会自动部署；也可以在 **Actions → Deploy to GitHub Pages → Run workflow** 手动触发。

发布地址是 `https://<你的用户名>.github.io/SichuanMahjong-Online/`。

构建时的 base 路径默认是 `/SichuanMahjong-Online/`（workflow 会自动按仓库名设置）。部署到别的地方时用环境变量覆盖，例如 `BASE_PATH=/ npm run build`。网站用 hash 路由（`#/join/123456`），刷新不会 404。

## 连不上怎么办（STUN / TURN / 信令服务器）

联机分两步：先通过 PeerJS 的信令服务器互相找到对方，再建立 WebRTC 点对点连接。

- **信令服务器**：默认用 PeerJS 官方免费的云服务（`0.peerjs.com`）。如果它不稳定，可以自己部署 [peerjs-server](https://github.com/peers/peerjs-server)，然后在 `src/config.ts` 的 `PEER_SERVER` 里填 `host` / `port` / `path` / `secure`。
- **STUN**：默认用 Google 和 Cloudflare 的公共 STUN，大多数家庭网络够用。
- **TURN**：有人在公司网络、部分手机网络或严格 NAT 下可能连不上，这时需要 TURN 中转。在 `src/config.ts` 的 `ICE_SERVERS` 里加一条：

  ```ts
  { urls: 'turn:turn.example.com:3478', username: 'user', credential: 'pass' },
  ```

  可以用 Cloudflare Calls、Metered 等提供的 TURN 服务，或者自己用 coturn 搭。
  ⚠️ 这是静态网站，写进代码里的 TURN 账号密码任何人都能看到。请用有流量限制或短期有效的凭据。

## 5 / 6 / 7 人局

人数在等待室里由房主选择，开局后不能改。每局都只有 4 人上桌，其余人是**临时观察者**：这局轮空，只能看牌河，积分保留，下局一定上场。临时观察者和**观战者**不一样：观战者只看不打、不计分、不进积分榜，也不参与轮换。

| 人数 | 每局轮空 | 下局谁下场                                             | 谁补位                                         |
| ---- | -------- | ------------------------------------------------------ | ---------------------------------------------- |
| 5 人 | 1 人     | 第一个点炮的人；如果第一个胡牌是自摸，就是自摸者的对家 | 上局的临时观察者，坐到下场者的位置             |
| 6 人 | 2 人     | 上面那个人，加上最后一个没胡的人                       | 上局的两位临时观察者，随机坐到空出来的两个位置 |
| 7 人 | 3 人     | 只有一家留下（本局第一个胡牌的人），其余三家下场       | 上局的三位临时观察者，随机坐到空出来的三个位置 |

首局由 1–4 号位上桌，5 号位以后先当临时观察者。每局结算窗口最上方会写明下一局谁下场、谁补到谁的位置。

## 规则配置

所有规则都在 `src/engine/rules.ts` 的 `DEFAULT_RULES` 里，改完重新构建即可。

| 配置项              | 默认值                                                 | 说明                                           |
| ------------------- | ------------------------------------------------------ | ---------------------------------------------- |
| `baseScore`         | 1                                                      | 底分                                           |
| `capFan`            | 3                                                      | 封顶番数                                       |
| `selfDrawBonus`     | `'base'`                                               | 自摸加底（`'base'`）或自摸加番（`'fan'`）      |
| `exchangeThree`     | `true`                                                 | 换三张                                         |
| `windRain`          | `true`                                                 | 刮风下雨（杠牌立即收钱）                       |
| `callTransfer`      | `true`                                                 | 呼叫转移（杠上炮时杠钱转给胡牌者）             |
| `multipleWinners`   | `true`                                                 | 一炮多响                                       |
| `passHuLock`        | `true`                                                 | 过水不胡                                       |
| `refundOnDraw`      | `true`                                                 | 流局退税                                       |
| `heavenEarthCap`    | `true`                                                 | 天胡、地胡直接封顶                             |
| `fan`               | 见下                                                   | 番型表                                         |
| `timers`            | 换三张 20 秒、定缺 20 秒、出牌 20 秒、碰杠胡响应 10 秒 | `enabled: false` 关闭所有计时                  |
| `spectator.slots`   | 2                                                      | 观战位数量                                     |
| `spectator.visible` | 全部 `false`                                           | 是否让观战者看到副露、定缺、手牌张数、番型明细 |

番型表（`fan`）：平胡 0、对对胡 1、清一色 2、七对 2、龙七对 3、清对 3、清七对 4、清龙七对 5、金钩钓 1、带幺九 2、将对 3、根 1（每个）、杠上花 1、杠上炮 1、抢杠胡 1、海底捞月 1、海底炮 1。

计分：每个付钱的人付 `底分 × 2^min(番数, 封顶)`；自摸时每家再多付 1 个底分。

观战者无论怎么配置都看不到任何人的手牌和换三张的牌。

## 规则假设

规则有歧义的地方，按下面的方式实现：

1. **番型叠加**：只取最高的一个牌型番（组合番型不重复计算，例如清对算 3 番，不是 2+1），再加根和附加番。
2. **金钩钓**：在对对胡的基础上 +1 番（合计 2 番）。
3. **带幺九**：每组面子和将都含 1 或 9。和清一色同时成立时取较大的一个。
4. **根**：手牌加副露里每有 4 张相同的牌算 1 根（杠、手里的 4 张、碰了再摸到第 4 张都算）；龙七对里组成「龙」的那 4 张不再算根。
5. **天胡**：庄家起手直接胡（在任何出牌、碰、杠之前）。**地胡**：闲家第一次摸牌就自摸，且之前没人碰杠。
6. **碰之后**只能出牌，不能马上杠或胡；暗杠、补杠只能在自己摸牌后做。
7. 牌墙摸完后打出的最后一张牌只能胡，不能碰、杠。
8. **一炮多响**后，由（从点炮者往下数）最后一个胡牌者的下家继续摸牌。
9. **呼叫转移**：杠上炮时，这个杠收到的全部杠钱转给（从点炮者往下数）第一个胡牌的人，一炮多响时不平分。
10. **抢杠胡**只能抢补杠；被抢后原来的碰保留为碰，补杠不收钱。
11. **查大叫**：最大番只算牌型和根，不算自摸、杠上花等附加番，受封顶限制；听的牌即使已经全部打出来了也算听牌。
12. **花猪**赔给每个不是花猪的未胡玩家封顶分。
13. **退税**：流局时没听牌的玩家和花猪，把本局收到的杠钱全部退给当初付钱的人（已经被呼叫转移的不退）。
14. 已经胡牌的玩家不参与流局结算，之后也不再付任何钱。
15. **庄家**：第一局房主坐庄；之后由上一局第一个胡牌的人坐庄；如果第一次胡牌是一炮多响，由点炮者坐庄；没人胡的流局，庄家连庄。
16. **换三张方向**：行牌是逆时针（下家在右手边），所以「顺时针换」= 给上家，「逆时针换」= 给下家。
17. **超时**：换三张、定缺按推荐自动选；出牌超时自动打刚摸到的牌（有缺门牌先打缺门）；碰杠胡超时自动「过」。超时不会替你胡牌。
18. **断线**：断线的玩家由电脑托管（托管时电脑能胡就胡），重连后恢复手动。
19. **玩家 ID 存在 sessionStorage 而不是 localStorage**：这样同一台电脑可以多开标签页当不同玩家，刷新页面仍能回到原座位。如果关掉标签页再打开，用同一个昵称加入，可以接回自己断线的座位。
20. 房主固定坐 1 号位，不能观战。
21. 观战者默认看不到碰、杠，所以牌河里被碰走的牌会直接消失。

5 / 6 / 7 人局的轮换规则有歧义的地方，按下面的方式实现：

22. **抢杠胡**视同点炮：被抢杠的人算「第一个点炮」。**一炮多响**时只下场那一个点炮的人。
23. **流局且没人胡**（5、6 人局）：本局输得最多的人下场；分数相同时，按从庄家开始的行牌顺序，庄家优先。
24. **6 人局「最后一个没胡的人」**：三家胡牌时就是剩下的那一家；流局时没胡的有好几个，取其中输得最多的。如果他和「第一个点炮 / 自摸者的对家」是同一个人，就从另外三人里再选本局输得最多的人下场（分数相同时，越晚胡牌或没胡的越先下）。
25. **7 人局「只有一家留下」**：留下的是本局第一个胡牌的人；没人胡的流局，留下本局赢得最多的人（分数相同时庄家优先）。
26. **庄家跟着座位走**：下局的庄家仍按原规则（第一个胡牌的人等）算出是哪个座位；如果那个座位换了人，由补位的人坐庄。
27. 临时观察者和观战者一样，只能看到牌河，看不到任何人的手牌。
28. 断线的玩家轮到上场时，由电脑托管。

## 项目结构

```
src/
  engine/        规则引擎（纯函数，和界面、网络无关）
    tiles.ts     牌的表示
    hand.ts      胡牌判定、听牌、向听数
    fan.ts       番型和计分
    game.ts      一局的状态机（reducer）
    room.ts      房间：座位、观战位、多局、累计分
    view.ts      viewFor：按接收者生成可见数据（唯一出口）
    ai.ts        电脑 AI（只读自己的视图）
    rules.ts     规则配置
  net/
    controller.ts  房主端：计时、电脑出牌、托管
    peer.ts        PeerJS 收发、心跳、重连
    protocol.ts    网络消息类型和协议版本
    storage.ts     玩家 ID、昵称、房主状态保存
  ui/              界面（原生 DOM）、牌面 SVG、中文文案
  config.ts        信令服务器、STUN/TURN 配置
tests/             Vitest 测试
docs/DESIGN.md     设计文档
```

更多设计细节见 [docs/DESIGN.md](docs/DESIGN.md)。
